EVENT BUS (widgets of the same canvas talk to each other):

  immediately receives the last value already published on that topic, if any. Topic "*" receives everything.
- Topics: lowercase, dotted, specific and stable, e.g. "sales.region.selected", "timer.finished", "todo.count".
- When your widget has a natural output (a selection, a total, a status), emit it after each change and once at
  startup with the restored state, as a small self-describing object: { region: "Nord", value: 12400 }.
- If a CANVAS section lists other widgets and it serves the request, connect to them: reuse their exact topic
  names and data shapes. Never rely on another widget being present: the widget must work alone too.
