Moteur de génération

Le serveur Prism génère avec sa propre configuration (backend/.env). Les réglages ci-dessous ne servent que sans serveur, par exemple sur GitHub Pages.

Aucun serveur Prism ici : sans clé, Prism affiche des widgets de démo. Avec votre clé Groq gratuite (console.groq.com), il génère et refactorise pour de vrai, directement depuis ce navigateur.

La clé reste dans ce navigateur et n'est envoyée qu'à api.groq.com. Sans « Mémoriser », elle est oubliée à la fermeture de l'onglet.
